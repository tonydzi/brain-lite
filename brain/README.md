# Второй мозг

Это личная папка владельца: она живёт в `My-Work/Brain`, никуда не отправляется и
не меняется обновлениями библиотеки. Раскладка та же, что у всех, кто пользуется методом,
поэтому любой помощник сразу понимает, где что лежит.

| Папка | Что это | Что сюда кладём |
|---|---|---|
| [00-Inbox](00-Inbox/README.md) | Входящие | Всё новое, что ещё не разобрано: быстрые мысли, ссылки, фото документов |
| [01-Conversations](01-Conversations/README.md) | Разговоры | Записи разговоров и переписок, которые владелец сам решил сохранить: о чём договорились, кто что обещал |
| [02-Decisions](02-Decisions/README.md) | Решения | Решения владельца: что решили, почему, что отбросили, когда пересмотреть |
| [03-Insights](03-Insights/README.md) | Выводы | Уроки и наблюдения: что сработало, что нет |
| [04-Projects](04-Projects/README.md) | Проекты | Дела с концом: ремонт, переезд, отпуск, учёба |
| [05-Resources](05-Resources/README.md) | Справочник | Полезное надолго: инструкции, рецепты, гарантии, статьи |
| [06-Concepts](06-Concepts/README.md) | Понятия | Идеи, которые повторяются в разных заметках: «семейный бюджет», «режим сна» |
| [07-People](07-People/README.md) | Люди | Карточки людей только с согласия владельца: кто это, откуда знакомы, о чём говорили |
| [08-Templates](08-Templates/README.md) | Шаблоны | Свои шаблоны владельца |
| [09-Bridges](09-Bridges/README.md) | Мосты | Заметки-связки между далёкими темами: как одна идея помогла в другом деле |
| [_originals](_originals/README.md) | Оригиналы | Исходники как есть, без правок: тексты, расшифровки, копии документов |

Три правила:

1. Оригинал отдельно, заметка отдельно, между ними ссылка (приём `lite-ingest`).
2. У каждой заметки хотя бы одна ссылка на другую заметку или на оглавление слоя.
3. Ничего не удаляем: устаревшее помечаем строкой «заменено на …».

Приёмы для мозга: `lite-ingest` (положить), `lite-brain` (найти, обзор недели, порядок),
`lite-decide` (решение), `lite-retro` (итоги). Obsidian по желанию: эта папка открывается в нём как обычный волт.
