# Изменения

## 1.2.0 (2026-11-03)

Установка короче и измеряется. Улучшения по разбору прошлых установок (FDE-петля).

- Установщик-спутник `install.sh` / `install.ps1` лежит в релизе рядом с архивом, в библиотеку не
  входит. Шаг 1 один раз узнаёт номер версии и берёт архив и установщик только из этого тега,
  сверяет сумму установщика и запускает его фазу `prepare`; шаг 2 после отдельного «да» снова
  сверяет и запускает `apply`. Помощнику больше не надо переписывать длинные блоки.
- Рецепт ничего не удаляет: прошлая `lite-prev` и черновики шагов уходят в `_archive`.
  Прерванную замену шаг 2 продолжает сам, если состояние однозначное.
- `lite-install.log`: реальное время каждого шага (начало, проверка, показ, согласие, установка).
- `START.md` / `START.en.md`: три вопроса до начала (есть ли приложение, какая система, где открыт помощник).
- `FIRST-TASK.md`: результат кладётся в мозг, новый чат находит его сам, без записки.
- `lite-check`: квитанция с одинаковыми полями, время из журнала, неизвестное `UNKNOWN`, без содержания задачи.
- Уже было в 1.1.x и сохранено: сверка суммы, проверка путей и ссылок, откат, латиница в PowerShell,
  `--proto '=https'`, отдельное «да» между шагами.

## 1.1.0 (2026-10-19)

- Закон метода в `law/`: FLOOR (пол безопасности) и CORE (как работаем), внешний вариант без наших
  машин и людей, очищенный от сборочных заглушек. FLOOR закреплён хешем: его изменение не уедет само.
- `AGENTS-CORE.md`: что помощник делает в начале каждого чата (закон, приёмы, проверка обновления).
  Обновляется вместе с библиотекой; памятка `My-Work/AGENTS.md` только ссылается на него, у старых
  установок шаг 2 один раз дописывает эту ссылку.
- 9 приёмов вместо 4: новые `lite-ingest`, `lite-brain`, `lite-decide`, `lite-retro` и `continue` из набора.
- Скелет второго мозга `brain/` (наша раскладка слоёв 00-09 и `_originals`): шаг 2 ставит его в
  `My-Work/Brain` один раз и больше не трогает. Простые шаблоны заметок в `templates/notes/`.
- Ежедневная проверка обновления: помощник в первом чате дня сверяет номер версии с последним релизом
  и говорит одной строкой; ничего не ставит. В релизе отдельный файл `VERSION`.
- Автопубликация: дважды в сутки робот GitHub подтягивает улучшения закона и `continue` из
  second-brain-starter-kit (`UPSTREAM.md` показывает коммит), проверяет стражем с политикой содержимого
  и полной матрицей тестов (Linux, Mac, Windows PowerShell 7 и 5.1) и только тогда выпускает релиз.

## 1.0.0 (2026-10-19)

- Отдельный репозиторий вместо папки `lite` внутри second-brain-starter-kit: другу
  приезжает 13 файлов, а не весь каталог из 978.
- Обновление одной фразой «обнови лайт»: релиз `brain-lite.zip` + `SHA256SUMS.txt`,
  проверка суммы и путей, показ изменений, замена с откатом `lite-prev` (UPDATE.md, Mac и Windows).
- Памятка `templates/My-Work-AGENTS.md` для личной папки.
- Правило 11: единственное разрешённое скачивание это рецепт UPDATE.md по просьбе владельца.
- Страж `lite-guard` в CI: только текст, лимит файлов и размера, без секретов, ссылки целы.
- Рецепт проверен тестами в bash, zsh, sh, dash и PowerShell 7 / Windows PowerShell 5.1:
  установка, обновление, двойной откат, и стоп на подмене суммы, zip-slip, симлинке,
  пути вне `lite/`, неполном архиве, застрявших `_old`/`_swap`, запуске изнутри `lite`.
- Первая установка идёт по тому же рецепту UPDATE.md, а не импровизацией помощника.
- Четыре приёма и FIRST-TASK перенесены без изменений из starter-kit v0.9.0.
