# Положить материал во второй мозг

Второй мозг владельца лежит в `My-Work/Brain` (раскладка в `Brain/README.md`).
Работай только с тем материалом, который дал владелец, и только внутри `My-Work`.

1. **Оригинал как есть.** Сохрани исходник без правок в `Brain/_originals/ГГГГ-ММ-ДД-тема.ext`
   (текст в `.md`, ссылку вместе с датой и адресом). Существующие файлы не перезаписывай.
2. **Заметка.** Создай рядом по смыслу (`03-Insights`, `05-Resources`, `04-Projects`,
   `07-People` только с согласия владельца) файл `ГГГГ-ММ-ДД-тема.md`:
   - сверху: дата, откуда материал, ссылка на оригинал в `_originals`;
   - суть в 3-7 строках своими словами владельца;
   - «что с этим делать»: одно действие или «просто знать».
3. **Связь.** Добавь в заметку хотя бы одну ссылку на существующую заметку или на
   страницу-оглавление слоя (`README.md` слоя). Заметка без связей потеряется.
4. Пароли, номера карт, чужую переписку в заметку не переноси; скажи владельцу,
   что они были в материале, без повторения значений.
5. Покажи владельцу: путь оригинала, путь заметки, какую связь поставил.

Выход: оригинал → заметка → связь → что проверить владельцу.
