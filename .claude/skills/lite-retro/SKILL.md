# Ретро сессии

Когда: владелец говорит «ретро», «подведи итоги» или закончил большую задачу.

1. Перечисли, что реально сделано в этом чате: файлы, результаты, решения. Только то,
   что можно показать; догадки отметь словом «не проверено».
2. Раздели на три корзины:
   - **Сохранить** (сработало, повторим): приём, файл, решение;
   - **Бросить** (не сработало или лишнее): и почему, одной строкой;
   - **Попробовать** (идея на следующий раз): одно действие, не больше трёх.
3. Для каждого «Сохранить» назови дом: заметка в `Brain/03-Insights` (урок),
   `Brain/02-Decisions` (решение, приём `lite-decide`), шаблон в `Brain/08-Templates`.
   С разрешения владельца запиши новым файлом с датой в имени, существующее не перезаписывай.
4. Одна строка: что из этого стоит рассказать Антону как улучшение общего набора
   (приём `lite-handoff`, записку отправляет сам владелец).

Выход: сделано → сохранить / бросить / попробовать → куда записано → одна строка для Антона.
Не хвали работу без улики и не придумывай цифры.
