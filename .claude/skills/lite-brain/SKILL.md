# Обслуживание второго мозга

Мозг: `My-Work/Brain`. Шаблоны заметок: `../lite/templates/notes` (от `My-Work`).

**Найти.** Сначала обычный поиск по именам и тексту в `Brain`. Покажи файл и строку,
отличай факт от догадки, назови, где искал. Пусто в одной папке не значит «нигде».

**Обзор недели** (по просьбе «обзор недели»): возьми шаблон `weekly-review.md`,
перечисли новые заметки за неделю по слоям, три главных вывода, одно решение на
следующую неделю. Сохрани новым файлом `Brain/03-Insights/ГГГГ-ММ-ДД-неделя.md`.

**Порядок** (по просьбе «наведи порядок»): найди заметки без единой ссылки,
дубли по теме и файлы во входящих старше двух недель. Предложи список до→после.
Перемещай и объединяй только после «да» владельца. Ничего не удаляй: дубль
помечается строкой «заменено на …» и остаётся на месте.

**Новый слой или папку** не создавай без просьбы: раскладка общая для всех, кто
пользуется методом, так проще помогать друг другу.

Выход: что нашёл или предлагаю → где → что сделать владельцу.
