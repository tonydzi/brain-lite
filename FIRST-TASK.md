# Первая полезная задача

Выберите одну настоящую задачу владельца. Уберите из входа пароли, банковские
данные, частную переписку третьих лиц и то, что не хотите отдавать выбранному приложению.
Помощник не ищет новые источники вне выбранной папки без просьбы.

Простой пример для первого запуска: **список дел превратить в список покупок**.
Владелец сам даёт свой список; помощник группирует его и сохраняет результат.
Проверка: каждый исходный пункт есть, ничего лишнего не добавлено, количество не выдумано.

Если настоящая задача пока не выбрана, используйте пробный вход:

```text
Для ужина нужны рис, морковь и лук. Для завтрака — овсянка и яблоки.
Лук уже есть дома. Разбей список покупок на ужин и завтрак. Количество не знаю.
```

Ожидаемое содержимое: ужин — рис и морковь, завтрак — овсянка и яблоки. Лук отдельно
отмечен как имеющийся дома. Нет цен, количества, магазина или новых продуктов,
придуманных помощником. Названия обеих групп уже есть во входе.
Эта проба проверяет механику; полезность для владельца доказывает его настоящая задача.

## Результат кладём в мозг

Сохраните результат одной заметкой в `My-Work/Brain/04-Projects/` (или в другой подходящий слой
мозга) с понятным заголовком и датой. Запомните для себя один вопрос, на который эта заметка
отвечает, например «что я покупаю к ужину?».

## Новый чат находит сам

1. Откройте **новый** чат в `My-Work`. Записку, текст ответа и путь к файлу не передавайте.
2. Задайте только свой вопрос.
3. Помощник сам ищет в `Brain` (приём `lite-recall`) и отвечает: путь к заметке и короткая цитата
   из неё.
4. Проверка (приём `lite-check`): файл по этому пути есть, цитата дословно совпадает с файлом,
   ответ не противоречит заметке. Нет файла, другая цитата или выдуманный факт: `FAIL`.
   Помощник не смог проверить: `UNKNOWN`.
5. Владелец говорит, полезен ли ответ. Это отдельный факт: найденная заметка ещё не польза.

Затем заполните квитанцию по приёму `lite-check` (поля там).

Статус первого запуска: «проверен на задаче владельца» только когда новый чат нашёл результат
сам и владелец подтвердил пользу. До этого: «проба выполнена», «результат сохранён, поиск не
проверен» или «ожидает первой задачи».
